# CoupleBudget

A simple local-first household budget app designed to be easy enough for both partners to use.

## v0.4.0

- Savings goals with progress, target date and estimated monthly amount needed
- Goal contributions and persistent local goal state
- Debt payoff planner with **avalanche** and **snowball** strategies
- Extra monthly debt-payment simulation, estimated payoff months/date and estimated interest
- Monthly report with savings rate, top spending category and over-budget count
- Existing CSV import, auto-category rules, upcoming bills and 30/60/90-day cash forecast retained
- JSON backup automatically includes goals and debts

No bank credentials, server, analytics or cloud account required. Debt projections are planning estimates, not financial advice.
