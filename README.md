# CoupleBudget

A simple household budget app designed to be easy enough that both partners actually use it.

## MVP

- Members
- Income/expense transactions
- Monthly category budgets
- Current-month dashboard
- Recurring bill list
- Search/filter
- JSON backup and CSV export
- Local-only storage
- Installable PWA manifest

## Run

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.
